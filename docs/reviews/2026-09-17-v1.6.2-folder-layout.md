# v1.6.2 (164): menu bar folder-row layout hotfix

Based directly on the v1.6.1 tag on `fix/1.6.2-folder-layout`. No v1.7 implementation is included. Public release metadata is unchanged; this is a local testing build, not a published release.

Long folder names/paths had higher layout priority than file counts and status, starving those columns of width and causing character wrapping and excessive height. The name/path now fills the remaining width, counts retain their natural width, and status has a bounded 110-point column. Paths truncate in the middle; names, paths and pending-work summaries expose their full text on hover. Pending summaries occupy at most two lines. Status meaning, network operations, controls, detailed rows and popover sizing are unchanged.
