## syncthingStatus 1.6.2

Fixes the menu bar dropdown when a folder has a long name or path. Names and paths now truncate to fit, keeping file counts, sizes, and sync status readable without oversized rows. Hover over truncated names, paths, or pending-work summaries to see the full text.

This is a focused layout fix based on v1.6.1.

**Requirements:** macOS 15.5 or later. Supports Apple Silicon and Intel. Syncthing must be installed and running separately.

**Updating from v1.6.0 or earlier?** Download the DMG manually once. Those versions can download in-app updates but cannot launch the installer. In-app installation works from v1.6.1 onward.
