## Decisions
- A local/global inventory difference alone is informational, not an unhealthy state; do not turn it into an alert or notification.
- Prefer the shared count for the compact overview because it is the more useful cross-device quantity. Keep both counts in Details for diagnosis.
- Accept Wave 3's two-worker-per-kind bound: deterministic tests cover fairness and generation isolation, while production bounded progress relies on the existing URLSession deadlines.
- Notification All/Selected mode governs per-folder completion notices only. Selected with no IDs means no per-folder notices; the separately named global “All Synced” notice remains controlled by the master notification toggle.
- Do not cancel an in-flight daemon mutation to honor a newer pause intent; let it resolve, apply the latest queued intent and reconcile through the refresh owner.
- Treat cleanup pagination and connection recovery as typed state: only a strictly decoded terminal page generation is actionable, and recovery controls never branch on localized error strings.
- Do not convert automated fixture coverage into a live-acceptance claim. Preserve the user's real daemon configuration, credentials, bookmarks and notification consent; run those cases with isolated preferences/responders and a disposable daemon.
